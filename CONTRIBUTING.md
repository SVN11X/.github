# Contributing

Every SVN11X repository follows [SVN11X/standards](https://github.com/SVN11X/standards).

1. Open an issue with the Task form. It asks for What, Why, Where, Do not touch, Done when and If unsure.
2. Work on a branch. Write commit messages with [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/).
3. Open a pull request and fill every section of the template.
4. The standard check must pass before the change is merged.

Rules for people and AI tools are in each repository's `AGENTS.md`.
