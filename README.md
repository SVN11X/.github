# .github

Default community files for every SVN11X repository that does not have its own: code of conduct, contributing guide, security policy and support.

- Pull request and issue templates are not kept here. Each repository gets its own from SVN11X/standards, so AI tools working on a local clone can read them.
- LICENSE is never inherited. Each repository has its own.
- Files inherited from here do not appear in clones. Anything an AI tool must read lives in the repository itself.
